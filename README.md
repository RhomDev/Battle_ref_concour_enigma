# Battle Ref Arena

## Télécharger l’APK Android

[Télécharger Battle Ref Arena 0.4.1 — émulateur PC x86_64 (.apk)](https://github.com/RhomDev/Battle_ref_concour_enigma/releases/download/android-v0.4.1/battle-ref-arena-x86_64.apk)

Glisse le fichier APK dans la fenêtre de l’émulateur, puis ouvre **Battle Ref Arena**.

Le catalogue contient **57 Refs et 20 Personnages** inspirés de mèmes d’animé, de jeu vidéo, de politique et de cinéma apparus après 2010. Les fiches éditables et leur modèle se trouvent dans [`data/`](data/README.md). Les fichiers du jeu se trouvent dans [`asset/`](asset/).

- Ouvrir [le plateau guidé](apercu/index.html) dans un navigateur. Activer le son dans Options, piocher, déployer Macron puis jouer Y.M.C.A. pour déclencher sa projection.
- Pour consulter les médias avec Pygame, installer les dépendances avec `python3 -m pip install -r requirements.txt`, puis lancer `python3 main.py`. Les boutons **Personnages** et **Références** ouvrent les collections.
- Dans Pygame, **Jouer** ouvre l’arène de démonstration. **Passer** donne un retour visuel. **Menu** ou **Échap** ramène à l’accueil.
